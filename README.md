# DuskLore Shorts — Avtomatlashtirilgan Horror AI YouTube Shorts (Android)

**DuskLore Shorts** — Google ekotizimi (Firebase AI Logic, Firestore, Google Sign-In, Google TTS va YouTube Data API v3) asosida ishlaydigan, Amerika ingliz tilida 15 soniyalik mistik va xalq afsonalari uslubidagi Horror Shorts videolarni yaratib har kuni **soat 7:00** da YouTube'ga joylovchi Android ilova.

## Telefonga APK yuklab o'rnatish (Kompyutersiz)

1. AI Studio'dan ushbu loyihani **GitHub'ga saqlang (Push / Sync)**.
2. GitHub sahifangizda **Actions** bo'limiga kiring — **"Build DuskLore Shorts APK"** jarayoni 2–3 daqiqada yashil belgi bilan tugaydi.
3. Tayyor APK faylni ikki joydan istalganidan yuklab oling:
   - **Eng osoni (Releases):** Ombor bosh sahifasidagi **Releases** → **`DuskLore-Shorts.apk`** ustiga bosing — fayl to'g'ridan-to'g'ri telefoningizga yuklanadi.
   - **Actions Artifacts:** **Actions** → oxirgi yashil yig'ilish → **Artifacts** → **`DuskLore-Shorts-APK`**.
4. Telefonda yuklangan `DuskLore-Shorts.apk` faylini ochib, Android ruxsatini (**Noma'lum manbalardan o'rnatish**) tasdiqlab o'rnating.

> **Eslatma:** Agar istalgan paytda APK'ni qayta yig'moqchi bo'lsangiz, GitHub'da **Actions → Build DuskLore Shorts APK → Run workflow** tugmasini bosing.
